# STEM School — оновлена версія

## Що змінено
- Головний hero-блок відцентровує текст і кнопку вертикально та горизонтально.
- Усі 4 уроки отримали інтерактивні завдання з полями відповіді.
- Додана автоматична перевірка чисел, тексту, вибору та радіокнопок.
- Неправильна відповідь не зараховується.
- Якщо користувач скасовує відмітку, закреслення прибирається.
- Прогрес зараховується лише після правильної відповіді.
- Доданий англійсько-український словник у кожному уроці.
- Для кожного слова є озвучення English та українською через Speech Synthesis API браузера.
- Додано фіолетові акценти та градієнт прогресу.
- Локальне збереження прогресу та експорт/імпорт залишилися.
